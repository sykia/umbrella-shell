# Umbrella Shell

Оформление стандартной панели задач Windows 11: расположение, размеры,
прозрачность и «Островки». Umbrella сохраняет Explorer системной оболочкой.
Проект находится в разработке; совместимость нативных модулей ограничена
конкретными системными DLL. Текущая версия исходников — **0.1.0**.

## Возможности

- Четыре вида панели: «Слитный», «Отдельный», «Островки» (виджеты, приложения, трей) и собственный [Umbrella Dock](docs/TASKBAR_DOCK.md). Dock работает в совместимом режиме с сохранением системной панели; desktop-проверки нового режима ещё не выполнены.
- Taskbar → «Конфигурация панели»: Task View после Widgets слева и произвольный порядок четырёх штатных групп справа на основной панели: скрытые значки, индикаторы ввода, сеть/громкость и часы/дата. Сеть и громкость переносятся вместе. Применение и сохранение — после подтверждения Windows; «Восстановить» возвращает исходный порядок. Перенос трея между областями, Start, Search и приложений пока отключён.
- Developer-команда `UmbrellaTaskbarHost.exe --inspect-components` снимает ограниченный нативный снимок компонентов, visual parents и ближайших ItemsRepeater-владельцев вложенных кнопок. Отдельный read-only hook не создаёт сессию оформления и не отправляет attach/configure/restore. Проверено чтение двух настоящих панелей; это не поддержка их перестановки.
- Изолированные native-тесты проверяют транзакционную перестановку собственной модели настоящего WinUI ItemsRepeater, динамические изменения и исходные клики. Это ещё не поддержка произвольного порядка компонентов Explorer.
- Межзонный layout-прототип находится только в `tests/fixtures`: проверка его подключения к Explorer вызвала сбой процесса, поэтому рабочий native-host не принимает эту операцию. Подробности и пределы проверки — в [оценке реализуемости](docs/TASKBAR_REORDER_FEASIBILITY.md).
- Четыре стороны экрана. Боковые кнопки доступны только на проверенной сборке Windows.
- Ширина/длина 40–100% и толщина 48–96 DIP для отдельной панели;
  у островков толщина 64–96 DIP. Размер значков остаётся системным.
- Сглаженные скругления и прозрачность всей панели, включая значки.
- Рабочую область при изменении толщины пересчитывает Explorer через размер XAML-фрейма панели; проверено с максимизированными окнами на двух мониторах. Snap Layouts, смешанный DPI и смена топологии требуют отдельной проверки.
- Автоскрытие снизу при полной ширине и стандартной толщине, без островков.
- Настройки с системным blur, открываемые через меню ПКМ панели после установки.

Изменения применяются автоматически и сохраняются. При следующем запуске Umbrella
восстанавливает выбранное оформление; после успешного изменения запускается
при входе в Windows без открытия настроек. «Вернуть исходный вид» отключает
это восстановление. Чтение значений и переключение страниц не меняют Windows.

## Использование и восстановление

1. Запустите `UmbrellaShell.exe` или выберите **Umbrella** в меню ПКМ панели.
2. Откройте **Taskbar** и выберите вид и параметры. Недоступные режимы отключены.
3. Escape, Alt+F4 и закрытие окна скрывают настройки, сохраняя сеанс оформления.
   Повторный запуск возвращает то же окно.
4. **Вернуть исходный вид** восстанавливает оформление. **Завершить Umbrella**
   в меню ПКМ полностью завершает GUI и возвращает исходное оформление.

При установке помощник меню запускается сразу и при входе текущего пользователя.
Оформление восстанавливает отдельный скрытый запуск UmbrellaShell. Полный выход GUI оставляет
помощник меню работающим. Удаление останавливает оба процесса и убирает автозапуск;
настройки хранятся вне каталога установки и сохраняются.

Резервная команда из каталога приложения:

```powershell
./UmbrellaShell.exe --restore-taskbar-style
```

До первого изменения создаётся журнал и запускается worker восстановления.
Проверяется идентичность Explorer и его окон. Совместный сбой процессов,
зависание Explorer и потеря питания не покрываются гарантией восстановления.
Явно выбранное автоскрытие остаётся настройкой Windows после выхода.

## Получение сборки

[Скачать установщик Windows x64](https://github.com/sykia/umbrella-shell/releases/download/v0.1.0/UmbrellaShell-0.1.0-windows-x64-setup.exe) ·

[Проверки CI](https://github.com/sykia/umbrella-shell/actions)

Первый релиз — предварительный Windows x64 installer без цифровой подписи.
Windows может показывать предупреждение о неизвестном издателе. SHA-256 рядом
с файлом позволяет проверить загрузку, но не заменяет подпись. Установка и
удаление в чистой VM ещё не проверены; это не стабильная проверенная поставка.
Актуальные результаты и ограничения: [проверки](docs/VERIFICATION.md).

**Автообновления отключены:** в приложении нет сетевого клиента и загрузчика
обновлений. Подписанный установщик сам по себе не добавляет автообновления.
[Реализация и оставшиеся условия](docs/UPDATES.md).

## Сборка из исходников

Если MSVC/SDK/Qt уже извлечены локально, а CMake/VS не зарегистрированы,
доступна прямая сборка `scripts/Build-Local.ps1`. Она не переустанавливает инструменты;
это отдельный путь без прогона CMake presets и компиляции Inno.

Нативные hook DLL используют статическую C++ runtime. Для модуля оформления исключена CFG-инструментация: на проверенном Explorer она блокировала подключение, хотя in-process fixture проходил. ASLR/DEP сохранены; полная новая installer/VM-проверка ещё не выполнена.
При локальной проверке разных копий остановите прежний `UmbrellaMenuHost.exe --stop`
из его собственного каталога перед запуском установленного помощника: меню имеет
одну сессию и открывает приложение рядом со своим exe.

Windows 11 x64, Visual Studio 2022 с C++/Windows SDK, CMake ≥ 3.25,
Qt **6.8.3 msvc2022_64**. Добавьте CMake в PATH и укажите свой Qt:

```powershell
$env:CMAKE_PREFIX_PATH = 'D:/Qt/6.8.3/msvc2022_64'
cmake --preset windows-msvc
cmake --build --preset release
ctest --preset release
./scripts/Test-Foundation.ps1
./scripts/Test-PublicRepository.ps1
```

Упаковка: `./scripts/Build-Package.ps1` (Inno Setup **6.4.3**, отсутствующий `stage`).
Скрипт собирает, проверяет, развёртывает Qt и создаёт installer/checksum в `dist`.
`-Signed` требует существующего сертификата и `signtool`; ключи в Git не хранятся.

Независимый core без Qt/Windows:

Core-тесты включают расчёт групп Taskbar и транзакционный откат. Отдельный target
`umbrella_xaml_layout_tests` проверяет реальные Windows XAML-кнопки в собственном
offscreen-окне; это не проверка перестановки компонентов Explorer. Его ограничения
и запуск описаны в [конструкторе](docs/TASKBAR_CONFIGURATION.md).

```powershell
cmake -S . -B build/core -DUMBRELLA_BUILD_APP=OFF -DBUILD_TESTING=ON
cmake --build build/core --config Release
ctest --test-dir build/core -C Release --output-on-failure
```

`--diagnostics` выводит JSON без GUI/GPU; `--ui-smoke` проверяет загрузку QML,
первый кадр D3D11 и переход логотипа, затем выходит. `UMBRELLA_SMOKE_DIR` включает
сохранение снимка. Smoke не меняет оформление панели и не проверяет установку.
Дополнительная QML-проверка без Win32-изменений: `python tests/taskbar_live_ui_test.py`
с PySide6 6.8.3. Проверки, меняющие настоящую панель, описаны отдельно.
