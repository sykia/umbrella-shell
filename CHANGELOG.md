# История изменений

Значимые изменения Umbrella Shell фиксируются здесь. Запланированные функции
не считаются выпущенными; версия сборки задаётся в CMakeLists.txt.

## Unreleased

- Добавлены включаемые DWM-миниатюры Dock (до восьми окон, выбор/закрытие, lazy-ресурсы), mock-проверки native ownership/error paths и геометрии preview. Исправлены обход всех окон группы при смене Z-order и повторное создание модели после завершения COM apartment. Убраны лишние QVariant-списки/notifications; измерен отдельный синтетический model-only сценарий. Реальные DWM/GPU/desktop проверки ещё не выполнены.

- Добавлен Umbrella Dock как четвёртый вид Taskbar: отдельные Qt Quick окна, событийная модель приложений, локальные закрепления и частичный импорт Windows, управление окнами, настройки темы/геометрии/автоскрытия и поддержка нескольких экранов. Совместимый режим сохраняет системную панель и настройки native-конструктора. Реальные desktop/resource/VM проверки ещё не выполнены; ограничения и изолированные fixtures — в docs/TASKBAR_DOCK.md.

- Профили Dock используют существующие устойчивые ID мониторов; добавлены packaged AppUserModelID/AppsFolder, сортировка закреплений, отложенная запись sliders, плавное скрытие с освобождением области ввода, системный accent-tint и общее с Dock живое превью. Проверки mixed DPI, переключения режимов и high contrast/reduced motion выполняются на изолированных данных; реальные packaged/monitor/ресурсные сценарии не заявляются проверенными.

## 0.2.0 — 2026-10-20

- Конструктор вынесен в Taskbar → «Конфигурация панели»: раскрывающаяся навигация, контрастные контейнеры, иконки и кнопки мониторов. Убрана кнопка применения: подтверждённый перенос оригинальной Task View после Widgets применяется с debounce и сохраняется после native-ack. Неподдерживаемые операции блокируются; одна кнопка «Восстановить» сбрасывает выбранную component-конфигурацию. Проверены Qt GUI, реальный hit-test/клик, сохранение, повторное применение новым владельцем и откат после смерти тестового host; второй монитор и остальные компоненты остаются без native-переноса.

- Исправлена синхронизация толщины Taskbar и рабочей области: поперечный размер XAML-фрейма передаётся Explorer вместо одного изменения HWND/подложки. Explorer пересчитывает rcWork каждого монитора; исходные свойства возвращаются существующим механизмом восстановления. Добавлен opt-in desktop-тест с настоящими максимизированными окнами; границы проверок — в docs/VERIFICATION.md.

- Доведено скрытое восстановление оформления: готовность Explorer и экранов по событиям, единственный владелец, независимые профили мониторов, ограниченные повторы handshake, отдельное подтверждённое размещение Task View и читающий startup-status. Добавлены локальная MSVC-сборка, desktop-проверки и подготовка обновления с резервной копией. Полный выход сохраняет выбор для следующего входа; «Вернуть исходный вид» отключает восстановление. Настоящий повторный вход в Windows ещё требует проверки владельцем.

- В настройки Taskbar добавлен конструктор: drag-and-drop между каталогом и тремя областями, порядок/вставка, расстояние и отдельные сохраняемые черновики мониторов. Проверенное применение ограничено оригинальной Task View после Widgets слева на основной панели через Translation с откатом; остальные компоненты и дополнительная панель — явно неподдерживаемое применение.

- Добавлен выключенный по умолчанию developer-прототип перемещения оригинальной Task View мышью в её XAML-контейнере: UIElement.Translation, проверка точных DLL, одна основная панель, автоматический откат. Локально проверены реальный drag/hit-test, штатный клик/Task View, фокус и восстановление при завершении тестового host; это не полный конструктор.

- Добавлен анализ возможности перестановки оригинальных компонентов Taskbar: ограничения Win32/UIA, варианты XAML/Composition, матрица компонентов и необходимые будущие проверки. Реализация и эксперименты не выполнялись.

- Исправлено подключение модуля оформления в Explorer: для UmbrellaTaskbarModule исключена CFG-инструментация, с которой реальный handshake отказывает при успешном in-process fixture. ASLR/DEP сохранены; CFG остальных модулей сохранён. Hook DLL используют статическую CRT. Требуется повторная CI/installer-проверка.

- Добавлен каталог системных контролов Taskbar: Win32/UIA-иерархия и геометрия двух панелей, скрытые узлы и отдельно неподтверждённые условные элементы. Исследование только чтением, без изменения Windows и приложения.

## 0.1.0 — первый бинарный preview, 2026-10-19

- Опубликованы неподписанный установщик Windows x64 и SHA-256 от sykia. Автообновления выключены.
- Релизная сборка и CI тега прошли; опубликованный installer скачан и проверен по checksum. Установка в чистой VM не выполнялась.


Записи ниже — история этапов разработки, начиная с последних изменений.
Промежуточные Shell Bar, темы и активность удалены при смене концепции;
актуальные возможности описаны в README, результаты проверок — в docs/VERIFICATION.md.


### Подготовка первого релиза

- По решению владельца первый выпуск публикуется как unsigned preview: installer и SHA-256, без сертификата и автообновления. Signed pipeline сохранён как необязательный путь при полной настройке секретов.
- В пакет включены upstream Qt 6.8.3 LICENSES/attributions, ссылки на corresponding source и license Inno; добавлен inventory runtime с версиями/SHA-256. Неиспользуемый software OpenGL исключён из D3D11 deployment.

- Исправлен полный выход скрытого GUI: QGuiApplication::quit повторно посылал Close и отклонялся фильтром скрытия. Явная команда теперь завершает event loop через exit(0), сохраняя RAII-восстановление; lifecycle-тест проверяет этот путь.

- В пакет включён актуальный комплект документации: README/CHANGELOG в корне, остальные Markdown в docs с рабочими относительными ссылками.

- Исправлено явное подключение COM для UI Automation при WIN32_LEAN_AND_MEAN: полная CMake/CI-сборка выявила зависимость, скрытую флагами native-прототипа.

- Автор в metadata приложения/установщика указан как sykia, добавлены ссылки проекта. Подписанный workflow теперь дополнительно проверяет deployed GUI с очищенным PATH.

- README и инструкции выпуска переписаны под оформление стандартной панели; старые Shell Bar, темы и учёт активности больше не описываются как текущие возможности.
- Добавлен единый отчёт docs/VERIFICATION.md. Старые CI-результаты не переносятся на новую реализацию.
- Уточнены отсутствие подписи preview, лицензионный комплект и границы невыполненных VM-испытаний. Автообновления остаются отключёнными до выполнения ADR-001; сетевого клиента нет.


### Сохранение оформления при закрытии настроек

- Escape/Alt+F4 и закрытие окна теперь скрывают настройки, сохраняя работающие расположение, островки, размеры и прозрачность. Повторный запуск/пункт Umbrella возвращает тот же экземпляр.
- В меню добавлено «Завершить Umbrella»: полный выход сохраняет штатное RAII-восстановление. Обновление/удаление предварительно завершают скрытый GUI.
- При скрытии запрашивается освобождение графических ресурсов; анимации зависят от видимости. Native-тест подтвердил show/quit скрытого владельца, Qt lifecycle-тест добавлен в CTest, но локально не собран. Подробности: docs/SETTINGS_LIFETIME.md.

### Сглаженные края и скрытые значки

- Скругления перенесены из CreateRoundRectRgn в CompositionGeometricClip с BorderMode.Soft. Win32-регионы ограничивают прямоугольные области ввода, не обрезая сглаженную границу.
- Исходные clip и BorderMode возвращаются при смене вида, выходе и смерти host; физические координаты переводятся в DIP.
- Окно скрытых значков располагается с внутренней стороны Taskbar и ограничивается монитором. Проверка --fixture покрывает обработчик открытия сверху/снизу и недопустимые координаты без открытия системного трея.
- DLL/host собраны; проверки геометрии, переключения видов и восстановления пройдены. Пользователь подтвердил гладкие края и правильное положение скрытых значков сверху в текущем просмотре.

### Исправление высоты подложки и трея

- Подложка масштабируется по короткой стороне окна; трей выравнивается по центру вместе с приложениями. Штатные размеры кнопок сохранены, внутренний кэш высоты Explorer не меняется.
- Исходные локальные XAML-свойства сохраняются один раз на сессию; при смене стороны overrides всех панелей снимаются до глобального изменения расположения. Восстановление не захватывает собственную предыдущую высоту.
- Добавлена отдельная запускаемая вручную Windows/UIA-проверка tests/taskbar_native_alignment.ps1, сравнивающая размеры реального содержимого на четырёх сторонах. Она временно меняет панель и восстанавливает её через закрытие stdin host.

### Единый выбор вида панели

- «Островки» перенесены из отдельного переключателя в три взаимоисключающих вида: «Слитный», «Отдельный», «Островки».
- Ширина/длина и высота/толщина доступны у отдельной панели и островков; ширина расположена первой. Слитный вид использует полную ширину и стандартную толщину, без ползунков размеров.
- Толщина пользовательских видов запоминается отдельно при переключении внутри страницы. Автоскрытие недоступно в островках; старые сохранённые сочетания флагов нормализуются без применения при открытии.

### Группы Taskbar и толщина

- «Островки» разделяют системную панель на группы погоды, приложений с Пуском/поиском и трея; общая подложка убирается, добавлены скругления и отступы.
- Добавлен ползунок толщины: высота горизонтальной/ширина вертикальной панели 48–96 DIP; островки используют 64–96 DIP, при включении выбирают 72 DIP.
- UIA-worker вне Explorer получает геометрию по событиям с ограниченным обходом и ожиданием перестройки дерева. Пустые/устаревшие маски отклоняются; исходный регион восстанавливается владельцем сессии.
- Автоскрытие явно возвращает 100%/48 DIP и отключает островки. Проверки QML дополнены совместимостью режимов и передачей последней толщины.

### Нативные размеры и боковая раскладка Taskbar

- Собственная C++ DLL удерживает ширину отдельной панели 40–100%; сбоку ползунок задаёт длину. Запросы автоматически поступают из QML, без кнопки применения.
- Автоскрытие снизу использует 100% ширины: переключатель явно возвращает её, поскольку уменьшенная ширина нарушает штатное скрытие. При скрытом окне отступ региона снимается для показа у края.
- На проверенной сборке Windows включена нативная вертикальная раскладка значков и трея слева/справа. Совместимость проверяется по RSDS GUID/age трёх системных DLL; неизвестные сборки отклоняются.
- Исправлена привязка вторичной панели к своему монитору. После выхода/смерти host восстанавливаются геометрия, исходный TaskbarLocation и локальный кэш функции; C++ DLL выгружается после завершения callbacks, кроме зависшего обработчика.
- MSVC собрал DLL/host; проверки прошли на двух мониторах 2560×1440/96 DPI: четыре стороны, размеры 40–100%, native reflow, обычное/аварийное восстановление. Полное C++ GUI, DPI/RDP и VM не проверены.

### Контекстное меню панели задач

- Независимые UmbrellaMenuHost/UmbrellaMenuModule добавляют Umbrella в меню стандартной панели без открытого окна настроек. Штатные команды диспетчера задач и параметров панели сохранены.
- Установщик запускает помощника после установки и добавляет автозапуск текущего пользователя; перед обновлением/удалением останавливает его, при удалении убирает запись Run. Поддержка ограничена точной проверенной сборкой Taskbar.View.dll.
- Пользователь подтвердил появление пункта. Проверены восстановление/выгрузка модуля и передача --settings соседнему exe; полный GUI и installer/VM не проверены. Подробности: docs/TASKBAR_CONTEXT_MENU.md.

### Размер окна настроек

- Окно увеличено до 1000×700, минимальный размер — 800×560. Левая колонка расширена до 220 пикселей; область настроек использует освободившееся пространство.

### Автоматическое применение Taskbar

- Убрана кнопка «Применить»: поддерживаемые параметры применяются автоматически после пользовательского действия, с объединением изменений за 180 мс и сохранением последнего значения во время pending.
- При старте записи нет; повторный перенос/журнал/регион и неизменившееся автоскрытие не обновляются при каждом шаге прозрачности.
- Неработающие боковые кнопки и ползунок ширины явно отключены вместо имитации изменения панели. Для их реализации ещё нужен собственный модуль Explorer.
- QML-тест проверяет отсутствие стартовой записи, объединение событий и busy/latest-value без Win32-изменений.

### Собственный Taskbar: ширина и боковая раскладка

- В отдельном виде плавно появляется ползунок ширины 40–100%, пока для макета.
- UI Automation выявила дефект боковой раскладки: HWND перемещается, значки остаются горизонтальными. Применение слева/справа и изменённой ширины заблокировано до собственного модуля Explorer.
- Добавлен собственный Win32-адаптер и worker восстановления без Windhawk. Python-прототип проверил alpha/region, обычный возврат и восстановление после смерти родителя; C++-сборка не выполнялась.

### Taskbar: автоскрытие Windows

- Добавлено явное применение штатного автоскрытия через Win32-адаптер: сохранение прочих флагов, обратная проверка и сообщения об отказе. Запуск не меняет панель.
- Python native smoke подтвердил изменение и возврат исходного режима. C++-сборка не выполнялась.

### Taskbar: интерфейс и предпросмотр

- Добавлена навигация Taskbar и четыре настройки на интерактивном макете: край, слитный/отдельный вид, прозрачность и автоскрытие.
- Добавлены анимации выбора, ползунка, переключателя и геометрии. На странице явно отмечено, что эти параметры меняют только предпросмотр; автоскрытие применяется отдельно.
- Интеграция расположения, вида и прозрачности ожидает выбора механизма работы с Explorer; ограничения описаны в docs/TASKBAR.md.

- Надпись Umbrella выровнена по центру левой колонки; буквы белые, ll — красные (#e7131b, основной красный логотипа).

### Главный экран настроек

- Логотип после загрузки проезжает слева направо, проявляя umbrella, затем перемещается в центр правой колонки и медленно вращается на главном экране.
- Надпись umbrella возвращает главный экран. Добавлено плавное увеличение логотипа и надписи при наведении; названия настроек и функции не добавлены.

### Загрузка и компоновка настроек

- Добавлено плавное вращение логотипа во время создания интерфейса; готовность связана с Loader, изображением и первым кадром.
- После готовности логотип плавно возвращается к исходному углу и перемещается в левый столбец; проявляются две пустые области без названий и функций.
- После перехода анимации прекращаются; прозрачный blur сохранён.

### Прозрачный blur настроек

- Окно настроек переведено на прозрачный blur-behind Windows без заголовка и обводки; оригинальный логотип сохранён.
- Фон можно перетаскивать, Escape/Alt+F4 завершают приложение. При отказе composition API используется непрозрачный фон.
- Прозрачный blur одобрен владельцем в Python/Qt-просмотре; C++-сборка и потребление ресурсов не проверены. Qt smoke не снимает системный backdrop.

### Перезапуск концепции

- Umbrella теперь развивается как дополнение Windows без замены её оболочки.
- Удалены панель, группы окон, скрытие taskbar, guard/recovery, автозапуск, темы, обои и учёт активности.
- Оставлено пустое окно настроек со статичным логотипом. Закрытие завершает приложение; старые данные не читаются и не удаляются.
- Следующие записи описывают предыдущую реализацию, а не текущие возможности.

### Переключение групп окон

- Исправлен пропуск окон без стандартного заголовка с WS_EX_APPWINDOW. Tool/owned/no-activate/elevated/cloaked окна по-прежнему исключены.
- Скрытие и показ при переключении выполняются одним DeferWindowPos-пакетом без смены геометрии, z-order и активации. Это уменьшает последовательную перерисовку; анимация всего рабочего стола не реализована.
- Кружки передают индекс кнопки напрямую, отражают активность через checked и сохраняют делегаты при обновлении состояния.
- Добавлены регрессии QML-маршрутизации, 50 переключений, новых окон, minimized/maximized placement и независимости двух мониторов (последняя проверка пропускается при одном мониторе). Результаты сборки и desktop-проверки фиксируются отдельно.

### Уточнения после проверки владельцем

- Учёт активности включает всё время активного окна, даже без клавиатуры/мыши, и само Umbrella; фоновые приложения одновременно не суммируются. Блокировка и сон исключаются, дискретность остаётся 5 секунд.
- Кнопки, поля, выпадающие списки и счётчики новых вкладок получили общий скруглённый стиль, анимированное нажатие/hover и клавиатурный фокус. Все переключатели используют единый компонент-таблетку.
- Логотип панели больше не сжимается стандартными отступами Button: PNG Umbrella отображается отдельно в заданном размере и исходных цветах.
- При живом запуске обнаружен отказ guard при повторном показе taskbar внутри обработки WinEvent. Добавлена ограниченная проверка после события (до трёх попыток через 50 мс), вместо немедленного отключения при этой гонке. Неуспех по-прежнему приводит к восстановлению Windows, непрерывного polling нет.

### Тема и активность

- Добавлены вкладки темы (обои, папка, шрифт, радиус, палитры и собственные темы) и локальной активности (opt-in, график, календарь и приложения).
- Smoke расширен на шесть страниц; владелец вновь разрешил сборку и запуск для проверки.
- Убрано затухание всей страницы, ухудшавшее контраст при переходе; анимации самих элементов сохранены. Добавлен запуск с открытыми настройками через --settings и проверка возврата окон при уменьшении количества групп.


### Переключатели и обработка событий панели

- Настройки замены панели и автозапуска используют собственные красные переключатели-таблетки с анимированным бегунком, hover и клавиатурным фокусом.
- Повторные TaskbarCreated объединяются в одну перерегистрацию, изменения DPI/экранов — в одно отложенное пересоздание. AppBar-позиционирование вынесено из синхронного native callback; z-order-only события не запускают согласование рабочей области.
- Исправлен пропуск обновления резерва AppBar при неизменившейся геометрии окна; перед возвратом Explorer собственные резервы снимаются.
- Кнопки пространств сохраняются при обновлении состояния и не сдвигают соседние модули: активное пространство — красная таблетка, занятые — тёмные кружки, свободные — светлые, без цифр.
- Добавлено сохраняемое количество пространств от 1 до 10 (по умолчанию 5). Изменение возвращает все окна и создаёт группы заново, чтобы окна не оставались в удалённых группах.
- После возобновления проверки сборка 457460b прошла CI (8 CTest) и запущена на Windows 11; обе системные панели скрыты, настройки доступны. Полное устранение наблюдаемого сбоя ещё требует desktop-проверки владельцем.

### Документация и статус проверки

- Все восемь публичных Markdown-документов согласованы с текущими исходниками,
  включая красную тему, модули, группы окон и ограничения восстановления.
- Дальнейшие сборки, функциональные тесты и GUI-запуски отложены по запросу
  владельца; последние изменения не объявляются проверенными на Windows 11.

### Стабильность и пространства на мониторах

- Панель якорится к краю физического монитора вместо перемещения вслед за согласованным Explorer прямоугольником; fullscreen не отправляет её на дно z-order.
- Убраны подсказки поверх кнопок. Конфигурация модулей поддерживает перетаскивание; зоны слева/центр/справа расположены горизонтально.
- По выбору пользователя добавлены независимые группы окон Umbrella на мониторах: пять анимированных кружков с реальной заполненностью, отдельный активный слот на каждом экране.
- Guard удерживает двойной shared-memory снимок скрытых окон и восстанавливает их при смерти GUI. Одновременная смерть обоих процессов не покрывается.
- Добавлен тест скрытия/восстановления синтетического окна с discovery, ограниченным PID fixture. Проверка реальных двух мониторов остаётся desktop-тестом.


### Настройки и модули панели

- Верхний бар переработан по новому референсу: светлая полоса 36 DIP, компактные капсулы и SVG-иконки, раскладка по умолчанию слева, звук справа. Существующие пользовательские зоны/край сохраняются.

- Текстовые псевдоиконки заменены собственными SVG одного линейного стиля; добавлены светлые и приглушённые варианты без зависимости от наличия глифов шрифта.

- По обратной связи фиолетовая палитра настроек заменена красной: плавное выделение навигации, hover кнопок и появление страниц.

- Переработаны настройки 680×440 по визуальным референсам Serpantinum: боковая навигация, карточки и конфигурация модулей. Системные кнопки окна убраны; логотип показывает/скрывает окно.
- Добавлена видимая только на странице приветствия анимация Umbrella: смена направления вращения, ускорение и увеличение при наведении.
- Добавлены четыре края панели, сохраняемые зоны модулей, раскладка активного приложения с переключением по клику, открытие параметров звука.
- Первоначальные кнопки назад/обзор/вперёд заменены собственными группами окон на каждом мониторе; системные Win+цифры не переназначаются, installer не меняет бинды.
- Добавлены проверки конфигурации и PNG страниц из QML smoke; действия с реальными рабочими столами и UIPI не покрываются CI.


### Подавление системной панели

- Guard скрывает основную и дополнительные панели Explorer через Win32, отслеживает повторный показ без polling и восстанавливает видимость при выходе/смерти GUI.
- Проверяются классы окон, системный путь Explorer, PID и время создания процесса; добавлено подтверждение applied до принятия запуска.
- Аварийное восстановление показывает панели также после смерти guard; добавлена команда --taskbar-status.
- Ограничение: классы Explorer не являются публичным API, out-of-context hook асинхронен; абсолютное отсутствие вспышек на всех сборках Windows не гарантируется.


### Shell Bar

- Добавлены панели Qt Quick/D3D11 на мониторах, логотип из ресурсов и расширяемые настройки.
- Штатное автоскрытие Windows включается после первого кадра и готовности guard; AppBar резервирует рабочую область.
- Добавлены восстановление исходного режима при выходе/смерти GUI, аварийная команда, горячая клавиша, журнал и opt-in автозапуск.
- Установщик предлагает запуск, удаляет Run и вызывает recovery; QML imports включены в deployment.
- Deployment smoke ожидает GUI-процесс и проверяет его ExitCode напрямую, с ограничением времени выполнения.
- Добавлены QML/D3D11 smoke и документация ручной VM-матрицы. Полное подавление taskbar, Blur и VM-проверки не заявляются.

Начальная версия исходников; наличие этой записи не означает публикацию
бинарного релиза или успешные испытания установщика.

- C++20/CMake и presets для Windows x64 / MSVC / Qt 6; границы core, Win32,
