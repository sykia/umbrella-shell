# История изменений

Значимые изменения Umbrella Shell фиксируются здесь. Запланированные функции
не считаются выпущенными; версия сборки задаётся в CMakeLists.txt.

## Unreleased

## 1.0.1 — 2026-10-26

- Installer 1.0.1 перенесён в `{autopf}\Umbrella Shell` (обычно
  `C:\Program Files\Umbrella Shell`) и требует UAC. Предыдущий per-user каталог
  больше не переиспользуется. Перед заменой файлов installer восстанавливает
  панель и останавливает helper как в прежнем `%LOCALAPPDATA%`, так и в новом
  каталоге; post-install процессы запускаются с исходными правами пользователя.

## 1.0.0 — 2026-10-26

- Боковой перенос больше не блокируется сохранённой горизонтальной конфигурацией
  компонентов: при Left/Right активный порядок временно снимается, но остаётся
  сохранённым для возврата на горизонтальную панель. Общий край записывается во
  все активные профили. Реальный UI-путь с «Островками» 100%/56 DIP и сохранённой
  схемой проверен на двух мониторах для Left и Right; автозапуск обновлён на
  проверенную сборку.

- Clock создан заново: горизонтальный `00:00` и вертикальный `00 / 00`,
  пустой фон, blur-карточка и blur внутри цифр, 12 цветов и настраиваемые интервалы. Все
  экземпляры используют один минутный VeryCoarseTimer; окна размещаются
  под значками Explorer и пропускают ввод вне редактора.

- Удалены прежние Clock и Music Widgets: QML-представления, модели,
  GSMTC/lyrics backend, шрифты и desktop transport controls. Старый
  `layoutV1` очищается. Редактор сохранён как чистая Fluent-основа:
  выровнены header, рабочая область и каталог, добавлены анимации
  появления, hover и выбора с учётом reduced motion.

- Конфигурация панели больше не показывает условные компоненты, которых нет в нативном снимке выбранного монитора (например, батарею или меню пера на неподдерживаемом ПК). Перетаскивание не уничтожает захватившую мышь карточку при перестроении QML-раскладки, а настройка расстояния доступна для любой подтверждаемой нативной конфигурации, а не только для устаревшего частного расположения Task View.

- Build-Local.ps1 работает в Windows PowerShell 5.1: добавлен совместимый fallback
  вместо недоступного в .NET Framework [IO.Path]::GetRelativePath, потому они больше
  не требуют PowerShell 7.

- Music Mini/Lyrics: области клика транспортных кнопок на рабочем столе с исключением значков/подписей и перекрывающих виджетов. Нативные input-only окна не меняют Explorer и не перехватывают мышь глобально; существующие media-команды вызываются после проверки свободной области.

- Исправлен отсутствующий блюр редактора: возвращён чистый compositor blur вместо плотной системной Acrylic-заливки, включены alpha buffers. Mica Music в редакторе пропускает тот же живой блюр, Clock — только внутри символов. GPU fallback использует общий фон конкретного монитора, координаты виджета и обновление по системным событиям; убрано растягивание одной статичной текстуры на каждый элемент.

- Восстановлена независимая Acrylic-подложка редактора Widgets: окно покрывает монитор без fullscreen presentation; дочерние окна виджетов не вызывают DWM API для фона редактора.

- Единые материалы виджетов Acrylic/Mica/Solid/Transparent с отдельным сохранением для каждого instanceId и компактным выбором в редакторе. Clock использует GPU-материал внутри формы цифр/даты; Music Mini/Lyrics — поверхность карточки. Системная тема, акцент, низкоразрешённая текстура обоев и fallback при выключенных эффектах/контрастности/software renderer. Без push и релиза.

- Music lyrics: исправлена потеря обычного текста при небольшой разнице длительности (начальная оценка совпадения), добавлены Unicode/metadata-нормализация, альтернативные запросы LRCLIB и последовательный fallback LRCLIB → Vagalume с локальным API-ключом → Lyrics.ovh. HTTP 503, 429, TLS/сеть, таймауты, неверный JSON и отсутствие текста различаются; ограниченные повторы соблюдают Retry-After. Ошибки не кэшируются как отсутствие. Диагностический режим показывает маршрут поиска без секретов и текстов ответов. Содержимое Music адаптируется к малому/большому размеру без изменения размещения окон.

- Исправлены слои Widgets: проверяемое подключение к Progman/WorkerW под SHELLDLL_DefView, события смены поколения Explorer без постоянного опроса, размещение по мониторам. Редактор переносит существующие визуальные элементы в свою сцену над Acrylic; выделение, перемещение, изменение размеров и удаление используют исходные instanceId и layoutV1. Управление музыкой доступно в отдельном окне и редакторе. Неизвестная структура оболочки отклоняется с сохранением раскладки. См. docs/WIDGET_DESKTOP_LAYER.md и ограничения ручной проверки.

- Clock Widgets: Inline/Stacked, скрываемая дата, системный формат времени, настройки шрифта/размера/цвета/прозрачности/тени, прозрачные окна и сохранение через редактор. Один таймер на границе минуты и системные события; независимый жизненный цикл от Music. Blocky Circle с OFL, Velocita/Cassiopea — внешние локальные personal-use файлы, системный fallback. Mixed-DPI и ресурсные бюджеты требуют ручной проверки.

- Music Widgets: Mini Player и Lyrics Player с общим событийным Windows GSMTC backend, обложкой, transport controls и перемоткой. Добавление/удаление и перемещение на выбранном мониторе, сохранение и отдельные окна после закрытия настроек. LRCLIB через HTTPS API с проверкой метаданных/длительности, ограниченным кэшем и синхронными/обычными текстами. Без привязки к сервису; остальные элементы каталога пока placeholders.

- Полностью удалён Dock: окна, настройки, закрепления, превью, интеграция автозапуска, сборочные цели и отдельные fixtures. Системная тема настроек перенесена в независимый Windows-адаптер SystemTheme; Taskbar и Widgets сохранены.

- Widgets: отдельные карточки подключённых мониторов, список записей сохранённой раскладки и настройка выбранного экрана. Редактор покрывает весь монитор вместе с панелью задач; дополнительная цветная подложка уменьшена с 12% до 2%. Радиус системного Acrylic задаёт Windows. При изменении топологии редактор закрывается без переноса на другой экран.

- Added Widgets foundation: metadata-only catalog, bounded versioned layout storage, Widgets settings page and on-demand Fluent setup window with system Acrylic, selection and close actions. No real widget instances or providers; existing UI smoke covers the foundation with temporary preferences.

- Настройки переработаны в стиле Fluent 2: нейтральные светлые/тёмные поверхности, карточки 8 DIP, акцентная навигация, Segoe UI Variable и Fluent Icons, общие кнопки/ползунки/флажки. Mica через документированный DWM API с резервным Acrylic/непрозрачным фоном; смена темы и эффектов обновляет материал. Переходы и состояния контролов учитывают отключение анимаций Windows и контрастную тему.

- Удалена система виджетов рабочего стола: редактор, часы, календарь, медиасессия и аудиоспектр, ресурсы и отдельные проверки. Системная кнопка Widgets остаётся частью раскладки Taskbar.

- Расширена desktop-проверка нативного расположения: явные флаги трёх видов панели, переходы между четырьмя сторонами и возврат геометрии после EOF. Это проверка общей стороны всех экранов; независимый боковой перенос пока не исправлен.

- Конструктор панели: скрытие найденных поддерживаемых компонентов в каталоге и возврат на панель, сохранение скрытых компонентов при обновлении состава, компактные островки от 48 DIP без принудительных 64/72, измеренная ширина содержимого Widgets с восстановлением local values/bindings. Добавлены Qt pointer-event, WinUI rollback/binding и compact-height проверки; UI smoke изолирован временными INI. Новая desktop-проверка поверх работающей пользовательской сессии не выполнялась.

- Объединены placement и clipping оригинальных компонентов для горизонтальных «Слитного», «Отдельного» и «Островков»: измеренная геометрия/DPI, rollback slots/HRGN/composition, подтверждение resize по событиям, транзакция выбранного монитора и сохранение подтверждённого порядка при native-loss. Desktop-проверка двух мониторов DPI 96 прошла, включая копию настоящих сохранённых профилей; mixed-DPI desktop, остальные flyout и VM failures не проверены. Подробности: docs/TASKBAR_CONFIGURATION.md.





- Planner и native coordinator принимают измеренную область назначения в DIP с сохранением отступов при resize. Отказ новой области восстанавливает предыдущую подтверждённую раскладку; скрытый XAML fixture покрывает толщины 48/64/96 DIP и недостаточную ширину. Подключение масок оформления и расширение поддержки настоящей панели ещё не выполнены.

- Добавлен сохраняемый предел двух незавершённых автоматических восстановлений; native replay запрещён при блокировке или отказе записи защиты. Бюджет возвращается после 60 секунд с прежними Explorer PID/мониторами. Несовместимая смена геометрии панели с сохранённым переносом отклоняется до сброса компонентов; поддержка переноса на островках и другом DPI пока не добавлена.

- Убрана ошибочная синхронизация сторон активных мониторов. Неподдерживаемое сочетание разных сторон с боковой панелью теперь отклоняется явно до сброса компонентов и изменений Windows; независимый верх/низ сохранён. Независимый вертикальный native layout ещё не реализован.

- Исправлена чрезмерная резервация стека в subclass Explorer: диагностический снимок теперь выделяется только по запросу в heap с обработкой отказа. После реального сбоя выявлен frame 125520 байт; после исправления 7936 байт. Добавлена проверка 13 вложенных сообщений на собственном скрытом fixture-окне. Повторный запуск с проблемными пользовательскими профилями пока не проверен.

- Разделено восстановление оформления и компонентов: перенос не включает старый отключённый профиль оформления. Сохранённые раскладки переживают несовместимый режим оформления. Геометрия native placement учитывает логические ActualOffset вместо промежуточной анимации; новые условные группы остаются в каталоге до явного размещения. Последняя правка геометрии проверена изолированно и на настоящих двух панелях: перенос, исходный клик Task View, сохранение, повторное применение и раздельный сброс.

- Конструктор поддерживает независимые подтверждённые раскладки двух панелей (v2 с миграцией v1), обнаружение видимых компонентов и перенос условных групп MainStack/NotificationAreaIcons. Сброс и отказ одной панели не стирают другую. Исправлен конфликт с compositor-анимацией; приложения намеренно остаются общей группой.

- Исправлен отказ переноса при видимой дополнительной группе SystemTray: правые компоненты размещаются от края с резервированием неподвижных групп. Причина отказа backend теперь показывается в конструкторе. Проверен настоящий перенос Пуска и восстановление при видимой MainStack.

- Межзонный native-адаптер подключён к конструктору основной панели и сохранению confirmedComponentV1. Общий host принимает переносы без процесса на движение мыши; поздний отказ отключает автоприменение только актуальной конфигурации. Приложения переносятся группой, Show Desktop сохраняет край. Второй монитор и системный ввод нового пути ещё требуют проверки.

- Developer Reorder: реальные межзонные слоты исходных компонентов без замены Layout; проверены четыре раскладки, динамическое приложение и независимый перенос часов двух панелей. GUI/persist нового пути и системный ввод ещё не готовы. Подробности: TASKBAR_REORDER_FEASIBILITY.md.

- Reorder: snapshot v5 различает индексный доступ и уведомления источника без выдачи права записи; чтение проверено на двух панелях. Изолированный coordinator отвергает скопированное перечисление и ограничивает цикл LayoutUpdated/Reset тремя попытками за проход UI. Notify-only индексная модель, динамические приложения и снятие подписок покрыты native fixtures; новые межзонные операции Windows ещё не включены.

- Изолированный межзонный coordinator сохраняет исходный Layout, отслеживает изменения модели и прекращает применение при конфликте владельцев. Native fixtures проверяют hit-testing, динамические элементы, stale source, восстановление слотов и ограничение повторов; новые переносы в Explorer не включены.

- Эксперимент с делегированием частного Taskbar layout вызвал сбой Explorer до подтверждения операции. Новый IPC-путь удалён из рабочего модуля; прототип сохранён только в изолированных fixtures без привязки к Explorer. Проверки собственных WinUI-контролов между тремя областями не означают поддержку этих переносов на системной панели.

- Reorder расширен до всех 24 порядков четырёх оригинальных групп справа: скрытые значки, индикаторы ввода, Quick Settings и часы. Сеть/громкость остаются одной группой; Show Desktop и условные блоки сохраняют свои слоты коллекции. Схема сохранения совместима с прежним обменом часов; неподдерживаемые межзонные переносы не подтверждаются. Read-only snapshot v4 сообщает имена исходных контейнеров и runtime-тип модели без выдачи права записи.

- Конструктор действительно меняет порядок оригинальных часов и Quick Settings справа на основной панели: часы/дата и общая группа сети/громкости. Меняется коллекция исходного StackPanel, включая layout slots и логический порядок, без Translation или копий. Добавлены связанный drag сети/громкости, native-проверка/откат, восстановление при закрытии host, сохранение и повторное применение. Перестановка может использовать действующий host оформления; Show Desktop и остальные peers остаются на месте. Свободный перенос всех компонентов и дополнительные мониторы ещё не поддержаны.
- Восстановление оформления больше не отправляет повторную команду текущей стороны панели: это предотвращает ненужную перестройку/поднятие Taskbar поверх полноэкранного приложения. Сквозная quiet-проверка нового трея прошла с сохранением фокуса игры, исходных стилей/геометрии и реестра.

- Native-диагностика компонентов использует отдельный read-only hook того же host/module: без attach/configure/restore и без остановки сессии оформления. Добавлен невидимый fixture, запрещающий эти сообщения, и `Build-Local.ps1 -NativeOnly`. Снимок проверен на двух настоящих панелях без изменения геометрии/рабочей области/фокуса; кэшированные task-list элементы за пределами панели больше не считаются видимыми. Новые переносы не объявлены готовыми.

- Конструктор Taskbar отменяет ещё не отправленное изменение при скрытии/сворачивании окна, уходе со страницы, отключении редактора и Escape; неактивный редактор не принимает новую команду. Это предотвращает неожиданное отложенное применение после ухода в другое приложение. Offscreen Qt-тесты с mock-backend проверяют отмену без изменения Windows.

- Reorder: native-снимок v3 определяет ближайший ItemsRepeater-владелец вложенной кнопки, его исходную обёртку и model index; snapshot-local IDs связывают общий контейнер/объект без адресов процесса. Поиск ограничен восемью родителями, не пересекает XamlRoot и не даёт права записи. Реальные WinUI fixtures проверяют сохранность вложенного содержимого при перестановке собственной модели; дополнительные переносы Explorer ещё не включены.

- Reorder: добавлена транзакция логического порядка собственной ItemsRepeater-модели с проверкой native indices, откатом частичных изменений и отказом от перезаписи reentrant-изменений. Изолированные тесты охватывают появление/исчезновение элементов и сохранение исходных Click. Адаптер не включён для чужой модели Explorer; дополнительные компоненты реальной панели пока не разблокированы.

- Reorder: native-снимок v2 читает настоящий WinUI 2 Layout и model index через versioned IItemsRepeater; данные Layout кэшируются в пределах одного снимка на parent. Изолированный fixture проверил системный CBS ItemsRepeater, перестановку/восстановление его собственной observable-модели и сохранение исходных UIElement. Модель Explorer этим не признаётся разрешённой к записи; новые переносы GUI ещё не включены.

- Taskbar Reorder, второй этап: ограниченный общий planner Left/Center/Right для нескольких групп и adapter-транзакция с проверкой текущего снимка, всех записей и обратным откатом даже частично завершившегося setter. Рабочий Task View использует эту транзакцию; повторная запись неизменной геометрии исключена. Модель приложений не переставляется: planner сохраняет относительные позиции экземпляров apps. Новые native-компоненты в GUI пока не включены.

- Taskbar Reorder, первый этап: проверка фактической XAML-геометрии перед native-ack, отказ при некорректных границах/пересечениях, повторная привязка после инвалидации по следующему запросу. При неудачном восстановлении прежней позиции удаляется её запись автоприменения. Переключение монитора отменяет отложенный drop; native-refused не ждёт полного IPC-таймаута. Добавлены переносимые тесты геометрии и ограниченная диагностика оригинальных компонентов/контейнеров `--inspect-components`. Перемещение остальных компонентов ещё не реализовано; диагностическое обнаружение не предоставляет capability.



## 0.2.0 — 2026-10-20

- Конструктор вынесен в Taskbar → «Конфигурация панели»: раскрывающаяся навигация, контрастные контейнеры, иконки и кнопки мониторов. Убрана кнопка применения: подтверждённый перенос оригинальной Task View после Widgets применяется с debounce и сохраняется после native-ack. Неподдерживаемые операции блокируются; одна кнопка «Восстановить» сбрасывает выбранную component-конфигурацию. Проверены Qt GUI, реальный hit-test/клик, сохранение, повторное применение новым владельцем и откат после смерти тестового host; второй монитор и остальные компоненты остаются без native-переноса.

- Исправлена синхронизация толщины Taskbar и рабочей области: поперечный размер XAML-фрейма передаётся Explorer вместо одного изменения HWND/подложки. - Все восемь публичных Markdown-документов согласованы с текущими исходниками,
  включая красную тему, модули, группы окон и ограничения восстановления.
- Дальнейшие сборки, функциональные тесты и GUI-запуски отложены по запросу

### Стабильность и пространства на мониторах

- Панель якорится к краю физического монитора вместо перемещения вслед за согласованным Explorer прямоугольником; fullscreen не отправляет её на дно z-order.
- Убраны подсказки поверх кнопок. Конфигурация модулей поддерживает перетаскивание; зоны слева/центр/справа расположены горизонтально.
- По выбору пользователя добавлены независимые группы окон Umbrella на мониторах: пять анимированных кружков с реальной заполненностью, отдельный активный слот на каждом экране.
- Guard удерживает двойной shared-memory снимок скрытых окон и восстанавливает их при смерти GUI. Одновременная смерть обоих процессов не покрывается.
- Добавлен тест скрытия/восстановления синтетического окна с discovery, ограниченным PID fixture. Проверка реальных двух мониторов остаётся desktop-тестом.


### Настройки и модули панели

- Верхний бар переработан по новому референсу: светлая полоса 36 DIP, компактные капсулы и SVG-иконки, раскладка по умолчанию слева, звук справа. Существующие пользовательские зоны/край сохраняются.

- Текстовые псевдоиконки заменены собственными SVG одного линейного стиля; добавлены светлые и приглушённые варианты без зависимости от наличия глифов шрифта.

- По обратной связи фиолетовая палитра настроек заменена красной: плавное выделение навигации, hover кнопок и появление страниц.

- Переработаны настройки 680×440 по визуальным референсам Serpantinum: боковая навигация, карточки и конфигурация модулей. Системные кнопки окна убраны; логотип показывает/скрывает окно.
- Добавлена видимая только на странице приветствия анимация Umbrella: смена направления вращения, ускорение и увеличение при наведении.
- Добавлены четыре края панели, сохраняемые зоны модулей, раскладка активного приложения с переключением по клику, открытие параметров звука.
- Первоначальные кнопки назад/обзор/вперёд заменены собственными группами окон на каждом мониторе; системные Win+цифры не переназначаются, installer не меняет бинды.
- Добавлены проверки конфигурации и PNG страниц из QML smoke; действия с реальными рабочими столами и UIPI не покрываются CI.


### Подавление системной панели

- Guard скрывает основную и дополнительные панели Explorer через Win32, отслеживает повторный показ без polling и восстанавливает видимость при выходе/смерти GUI.
- Проверяются классы окон, системный путь Explorer, PID и время создания процесса; добавлено подтверждение applied до принятия запуска.
- Аварийное восстановление показывает панели также после смерти guard; добавлена команда --taskbar-status.
- Ограничение: классы Explorer не являются публичным API, out-of-context hook асинхронен; абсолютное отсутствие вспышек на всех сборках Windows не гарантируется.


### Shell Bar

- Добавлены панели Qt Quick/D3D11 на мониторах, логотип из ресурсов и расширяемые настройки.
- Штатное автоскрытие Windows включается после первого кадра и готовности guard; AppBar резервирует рабочую область.
- Добавлены восстановление исходного режима при выходе/смерти GUI, аварийная команда, горячая клавиша, журнал и opt-in автозапуск.
- Установщик предлагает запуск, удаляет Run и вызывает recovery; QML imports включены в deployment.
- Deployment smoke ожидает GUI-процесс и проверяет его ExitCode напрямую, с ограничением времени выполнения.
- Добавлены QML/D3D11 smoke и документация ручной VM-матрицы. Полное подавление taskbar, Blur и VM-проверки не заявляются.

## 0.1.0 — фундамент, 2026-10-17

Начальная версия исходников; наличие этой записи не означает публикацию
бинарного релиза или успешные испытания установщика.

### Добавлено

- C++20/CMake и presets для Windows x64 / MSVC / Qt 6; границы core, Win32,
  Direct3D 11 и Qt Quick/QML без создания интерфейса оболочки.

- Политика допуска обновлений, каналы Stable/Beta и CTest-проверки политики.

- UI и замена Explorer отсутствуют. Нет фоновых сервисов и сетевой активности.

  и автоматический откат не реализованы; обновления отключены.
