# История изменений

Значимые изменения Umbrella Shell фиксируются здесь. Запланированные функции
не считаются выпущенными; версия сборки задаётся в CMakeLists.txt.

## Unreleased

### Настройки и модули панели

- Переработаны настройки 680×440 по визуальным референсам Serpantinum: боковая навигация, карточки и конфигурация модулей. Системные кнопки окна убраны; логотип показывает/скрывает окно.
- Добавлена видимая только на странице приветствия анимация Umbrella: смена направления вращения, ускорение и увеличение при наведении.
- Добавлены четыре края панели, сохраняемые зоны модулей, раскладка активного приложения с переключением по клику, открытие параметров звука.
- По выбору пользователя рабочие пространства используют совместимые кнопки назад/обзор/вперёд; системные Win+цифры не переназначаются, installer не меняет бинды.
- Добавлены проверки конфигурации и PNG страниц из QML smoke; действия с реальными рабочими столами и UIPI не покрываются CI.


### Подавление системной панели

- Guard скрывает основную и дополнительные панели Explorer через Win32, отслеживает повторный показ без polling и восстанавливает видимость при выходе/смерти GUI.
- Проверяются классы окон, системный путь Explorer, PID и время создания процесса; добавлено подтверждение applied до принятия запуска.
- Аварийное восстановление показывает панели также после смерти guard; добавлена команда --taskbar-status.
- Ограничение: классы Explorer не являются публичным API, out-of-context hook асинхронен; абсолютное отсутствие вспышек на всех сборках Windows не гарантируется.


### Shell Bar

- Добавлены панели Qt Quick/D3D11 на мониторах, логотип из ресурсов и расширяемые настройки.
- Штатное автоскрытие Windows включается после первого кадра и готовности guard; AppBar резервирует рабочую область.
- Добавлены восстановление исходного режима при выходе/смерти GUI, аварийная команда, горячая клавиша, журнал и opt-in автозапуск.
- Установщик предлагает запуск, удаляет Run и вызывает recovery; QML imports включены в deployment.
- Deployment smoke ожидает GUI-процесс и проверяет его ExitCode напрямую, с ограничением времени выполнения.
- Добавлены QML/D3D11 smoke и документация ручной VM-матрицы. Полное подавление taskbar, Blur и VM-проверки не заявляются.


### Добавлено

- История изменений, правила локальной работы Codex и проверка состава
  публичного репозитория перед коммитом/в CI.
- Исключения Git для локальных инструкций, секретов, кэшей и результатов сборки;
  единые окончания строк в Git.
- Публичный репозиторий `sykia/umbrella-shell`; подтверждены успешные проверки
  Linux core и Windows-сборки, трёх CTest-тестов, deployment smoke test
  и компиляции unsigned установщика в GitHub Actions.

### Исправлено

- Согласованы каталоги установки exe и Qt DLL: готовый пакет использует
  единый корневой runtime-каталог. Добавлена app-local поставка MSVC runtime
  средствами CMake вместо отдельного elevated redistributable installer.
- GitHub Actions закреплены по проверенным SHA; несуществующий тег `v4`
  у install-qt-action заменён конкретной версией 4.4.1.
- Подготовка Inno Setup в CI допускает установку закреплённой версии поверх
  более новой версии runner; ошибка provisioning останавливает сборку.
- Документация подготовки репозитория, границы реализованных возможностей
  и инструкции по проверке/публикации приведены к текущему состоянию.

## 0.1.0 — фундамент, 2026-10-17

Начальная версия исходников; наличие этой записи не означает публикацию
бинарного релиза или успешные испытания установщика.

### Добавлено

- C++20/CMake и presets для Windows x64 / MSVC / Qt 6; границы core, Win32,
  Direct3D 11 и Qt Quick/QML без создания интерфейса оболочки.
- Диагностический CLI с `--diagnostics` и `--restore-explorer`.
- Политика допуска обновлений, каналы Stable/Beta и CTest-проверки политики.
- Per-user Inno Setup, Qt deployment и PowerShell-скрипты сборки/упаковки.
- Workflows CI и подписанного GitHub Release с обязательным сертификатом.
- Документация архитектуры, доверия обновлениям, восстановления, лицензий
  и ручной VM-проверки.

### Ограничения

- UI и замена Explorer отсутствуют. Нет фоновых сервисов и сетевой активности.
- Автообновления, runtime-проверка подписей, транзакционная замена файлов
  и автоматический откат не реализованы; обновления отключены.
