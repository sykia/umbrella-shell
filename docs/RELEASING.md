# Сборка и выпуск

Текущая версия CMake — 0.1.0. Результаты прежней Shell Bar не подтверждают
текущую реализацию системной панели. Свежие проверки: [VERIFICATION.md](VERIFICATION.md).

## Разработческая сборка

Требования и команды приведены в [README](../README.md). `Build-Package.ps1`
требует отсутствующего `stage`: старые DLL не должны попадать в новый пакет.
Не удаляйте неизвестные каталоги ради повторного запуска; используйте чистый checkout
или предварительно сохраните предыдущий deployment.

CI собирает MSVC x64 / Qt 6.8.3, выполняет CTest, развёртывает Qt и компилирует
неподписанный установщик Inno Setup 6.4.3. Deployed smoke запускается с системным
PATH без Qt development paths. Linux собирает и проверяет только core.
Это не испытания установки/удаления или совместимости со всеми Windows 11.

## Публичный бинарный релиз

1. Проверить diff, metadata и staged index через `Test-PublicRepository.ps1`,
   выполнить `Test-Foundation.ps1`, сборку/CTest и deployment smoke.
2. Включить лицензионные тексты/уведомления фактически поставляемых Qt/MSVC
   компонентов и перечень зависимостей. Не придумывать лицензию проекта.
3. Выполнить VM-матрицу ниже и записать фактические результаты.
4. Подготовить защищённый GitHub environment `release` и существующий
   доверенный code-signing PFX. Секреты `WINDOWS_CERTIFICATE_BASE64` и
   `WINDOWS_CERTIFICATE_PASSWORD` не должны попадать в исходники или логи.
   Hardware/cloud-only ключ требует отдельного signing adapter.
5. После выполнения условий перенести записи Unreleased в версию с датой выпуска,
   сверить версию CMake и создать соответствующий тег `v0.1.0`.
   Тег запускает `release.yml`: подпись пяти собственных exe/DLL, uninstaller
   и setup, проверка Authenticode, SHA-256 и публикация GitHub Release.

Workflow отказывает при отсутствии signing secrets; обход этого условия
не предусмотрен. Повторно существующие release/assets не перезаписываются.
До выполнения условий допустим черновик релиза, но не объявление подписанной
стабильной поставки. Автор коммитов проекта — sykia; bot-run workflow не является
личной подписью автора. Автообновления этот workflow не включает.

## Ручная VM-матрица

- Чистая Windows 11 x64 без Qt/SDK, обычный пользователь, путь с пробелами и кириллицей.
- Установка per-user без UAC, diagnostics, открытие GUI и меню ПКМ.
- Logon помощника меню, закрытие/возврат настроек и полный выход с восстановлением.
- Обновление поверх текущей версии, повторная установка, открытое меню и занятые DLL.
- Отмена/ошибка установки, недостаток места и сохранение пользовательских настроек.
- Удаление из Windows Settings: процессы завершены, оформление возвращено,
  ярлыки/Run удалены, настройки сохранены, Explorer работает.
- Подписи setup, собственных installed exe/DLL и uninstaller; SmartScreen отдельно.
- Панель на четырёх сторонах, два монитора, разные DPI/RDP, перезапуск Explorer,
  обычный и аварийный выход. На неподдерживаемой сборке — корректный отказ.

Компиляция Inno не заменяет эту матрицу. In-place Inno не предоставляет
транзакционного отката после потери питания. Условия автообновления описаны
в [UPDATES.md](UPDATES.md).
