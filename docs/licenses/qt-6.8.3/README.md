# Лицензионные уведомления Qt 6.8.3

Приложение динамически использует неизменённые Qt runtime из официальной поставки
Qt 6.8.3 для MSVC 2022 x64. В подкаталогах сохранены upstream LICENSES,
уведомления и qt_attribution.json третьих сторон модулей qtbase, qtdeclarative и
qtsvg. Это набор уведомлений исходных модулей, включая необязательные компоненты;
точный состав поставленных exe/DLL и их SHA-256 записан в docs/runtime-inventory.json.
Файлы Qt не являются собственным кодом Umbrella и сохраняют свои лицензии.

Исходники соответствующей версии:

- [Полный Qt 6.8.3 source archive](https://download.qt.io/archive/qt/6.8/6.8.3/single/qt-everywhere-src-6.8.3.tar.xz)
- [qtbase c07c2d5a527a644d36e7853d55132ae38921682f](https://github.com/qt/qtbase/tree/c07c2d5a527a644d36e7853d55132ae38921682f)
- [qtdeclarative 2ec235a2235a119887683e55787b93f99dc5f12f](https://github.com/qt/qtdeclarative/tree/2ec235a2235a119887683e55787b93f99dc5f12f)
- [qtsvg c75099a75e81df35e7347a65e301bbf1011831a5](https://github.com/qt/qtsvg/tree/c75099a75e81df35e7347a65e301bbf1011831a5)

Динамические библиотеки Qt можно заменить совместимой собственной сборкой;
Umbrella не проверяет и не блокирует такую замену. Применимые LGPL/GPL тексты
и уведомления находятся в LICENSES каждого модуля. Разрешена обратная разработка
комбинированного приложения для отладки изменений LGPL-библиотек в объёме,
предусмотренном применимой лицензией. Это не предоставляет общую лицензию
на собственный код Umbrella или товарные знаки третьих лиц.
