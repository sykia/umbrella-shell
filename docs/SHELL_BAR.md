# Прежняя Shell Bar

Собственная Shell Bar удалена из текущей сборки. Она больше не создаёт AppBar,
не скрывает системную панель ради замены и не управляет группами приложений.
Темы/обои и учёт активности прежней реализации также отсутствуют.

Этот путь сохранён для старых ссылок. Актуальная функция — оформление стандартной
панели Explorer: [TASKBAR.md](TASKBAR.md). Устройство приложения:
[ARCHITECTURE.md](ARCHITECTURE.md). История прежней реализации доступна в Git
и [CHANGELOG.md](../CHANGELOG.md); старые CI-результаты к текущему коду не относятся.
