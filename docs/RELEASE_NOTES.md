# Umbrella Shell 0.2.0

Предварительный выпуск для Windows 11 x64. Автор: sykia.
Неподписанная сборка обозначается GitHub как prerelease; SHA-256 не заменяет подпись.

## Изменения

- Фоновый запуск и восстановление сохранённого оформления при входе в Windows,
  ожидание готовности Explorer, единственный владелец и профили двух мониторов.
- Исправлен пересчёт рабочей области rcWork при изменении толщины и стороны панели.
- Отдельная страница конструктора с автоматическим применением подтверждённых
  операций, сохранением после native-успеха и восстановлением выбранного монитора.

## Установка

Скачайте UmbrellaShell-0.2.0-windows-x64-setup.exe и установите для текущего
пользователя. Настройки хранятся отдельно и сохраняются при обновлении.
После изменения оформления оно сохраняется автоматически; закрытие окна скрывает
настройки. Полный выход возвращает исходный вид до следующего входа, а команда
«Вернуть исходный вид» также отключает автоматическое восстановление.

## Проверки и ограничения

Объединённая локальная MSVC/Qt 6.8.3 сборка установлена и восстановила реальные
панели двух мониторов без перезагрузки. Проверены рабочая область, UI конструктора,
скрытый старт и повторный запуск процесса. Настоящий повторный вход в Windows
ещё не подтверждён. Чистая VM-установка и смешанный DPI не проверены.

Конструктор нативно поддерживает только подтверждённый перенос оригинальной
Task View после Widgets на основном мониторе при исходной нижней панели 48 DIP
и масштабе 100%. Остальные компоненты и второй монитор не имеют нативного переноса.
Автоскрытие остаётся общей настройкой Windows; разные вертикальные стороны
мониторов ограничены общей нативной настройкой. Несовместимые функции пропускаются
с сохранением предпочтений. Поддержка зависит от версии Windows.

Автообновления выключены. Новой версии требуется ручная установка.
Подробности и границы проверок: docs/VERIFICATION.md и docs/STARTUP_RECOVERY.md.
