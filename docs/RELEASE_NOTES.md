# Umbrella Shell 0.1.0 — подготовка первого релиза

Статус: кандидат к первому релизу, не подтверждение публичной подписанной поставки.

## Текущие возможности

- Оформление стандартной панели Windows 11 вместо собственной Shell Bar.
- Слитный, отдельный вид и островки; размеры, прозрачность, сглаженные края.
- Верх/низ и нативные боковые раскладки на проверенных системных DLL.
- Автоприменение после действия пользователя; открытие настроек Windows не меняет.
- Меню Umbrella на панели, возврат скрытого окна и отдельная команда полного выхода.
- Восстановление оформления при штатном выходе и worker на случай смерти GUI.

## Ограничения

Совместимость зависит от точных DLL Windows. Прозрачность затрагивает значки.
Автоскрытие доступно снизу при 100%/48 DIP без островков и остаётся настройкой
Windows после выхода. Выбор оформления не применяется при входе автоматически.
Совместный сбой процессов/потеря питания не покрываются восстановлением.
Собственные рабочие столы, темы, обои и учёт активности в этой версии отсутствуют.

Автообновления **отключены**: downloader, appcast и runtime-проверки подписи
не реализованы. Неподписанные artifacts предназначены только для разработки.
Подпись, лицензионный комплект и установка/upgrade/uninstall в чистой Windows VM
остаются условиями публичного бинарного выпуска.
