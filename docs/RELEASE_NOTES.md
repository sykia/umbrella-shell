# Umbrella Shell 0.1.0

Первый предварительный выпуск для **Windows 11 x64**. Автор: sykia.
Установщик **не подписан цифровым сертификатом**; Windows может показывать
предупреждение о неизвестном издателе. SHA-256 приложен отдельно и не заменяет подпись.

## Что работает

- Оформление стандартной панели Windows: слитный/отдельный вид и островки.
- Расположение, ширина/длина, толщина, прозрачность и сглаженные края.
- Боковая нативная раскладка на точном проверенном наборе DLL Windows.
- Автоматическое применение после действия пользователя, без записи при открытии.
- Umbrella в меню ПКМ панели; закрытие скрывает настройки, сохраняя оформление.
- «Завершить Umbrella» полностью выходит и возвращает исходное оформление.
- Worker/журнал для восстановления после смерти GUI; резервная команда
  `UmbrellaShell.exe --restore-taskbar-style`.

## Установка

Скачайте `UmbrellaShell-0.1.0-windows-x64-setup.exe` и запустите его.
Установка выполняется для текущего пользователя без UAC. После установки откройте
Umbrella через «Пуск» или ПКМ панели → Umbrella. Помощник меню запускается при входе;
выбранное оформление при входе автоматически не применяется.
Пользовательские настройки сохраняются при удалении.

## Ограничения

Это экспериментальная версия. Поддержка меню/боков зависит от точных DLL Windows;
на неизвестных сборках эти возможности отключены. Прозрачность затрагивает значки.
Автоскрытие доступно снизу при 100%/48 DIP без островков и остаётся настройкой Windows.
Совместный сбой восстановительных процессов, зависание Explorer и потеря питания
не покрываются гарантией восстановления. Чистая VM-установка/upgrade/uninstall,
все DPI/RDP и длительная стабильность ещё не проверены.

**Автообновления выключены.** В этой версии нет downloader/appcast и runtime-проверки
подписей; новая версия устанавливается вручную из GitHub Releases. Собственная
Shell Bar, рабочие столы, темы/обои и учёт активности отсутствуют.

Полная C++/Qt-сборка, все восемь CTest, deployment smoke и Inno-компиляция прошли
[релизный CI](https://github.com/sykia/umbrella-shell/actions/runs/39248989460).
Актуальный отчёт: [VERIFICATION.md](https://github.com/sykia/umbrella-shell/blob/main/docs/VERIFICATION.md).
Уведомления Qt и ссылки на соответствующие исходники включены в пакет.
Лицензия собственного кода пока не выбрана владельцем.
