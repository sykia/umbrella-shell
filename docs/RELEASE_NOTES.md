# Umbrella Shell 1.0.0

Первый полный выпуск Umbrella Shell для Windows 11 x64. Автор: [sykia](https://github.com/sykia).

## Главное

- Три оформления стандартной панели задач Explorer: «Слитный», «Отдельный» и «Островки».
- Настройка положения, длины, толщины, прозрачности и скруглений панели по мониторам.
- Визуальный конструктор поддерживаемых системных компонентов с сохранением и транзакционным откатом.
- Размещение панели по четырём сторонам экрана в пределах документированных ограничений Windows.
- Desktop Clock Widgets: горизонтальные и вертикальные часы, 12 цветов, интервалы и три варианта фона.
- Fluent 2 настройки с Mica/Acrylic, системной темой, акцентом, high contrast и reduced motion.
- Восстановление исходного оформления, ограниченное аварийное восстановление и запуск для текущего пользователя.

Umbrella не заменяет Explorer, не устанавливает системную службу и не отправляет сетевой трафик. Автообновления отключены.

## Установка

1. Скачайте `UmbrellaShell-1.0.0-windows-x64-setup.exe` и файл `.sha256`.
2. При желании проверьте SHA-256: `Get-FileHash .\UmbrellaShell-1.0.0-windows-x64-setup.exe -Algorithm SHA256`.
3. Запустите установщик. Установка выполняется только для текущего пользователя.
4. Откройте Umbrella из меню «Пуск» или из контекстного меню панели задач.

Настройки хранятся отдельно от каталога программы и сохраняются при обновлении или удалении. Для аварийного возврата используйте пункт **Restore taskbar appearance** в меню «Пуск» либо команду `UmbrellaShell.exe --restore-taskbar-style`.

## Совместимость и известные ограничения

- Требуется Windows 11 x64 (build 22000 или новее).
- Нативная интеграция зависит от совместимости системных DLL конкретной сборки Windows; неподдерживаемая операция должна завершаться отказом без частичного применения.
- Сочетание разных вертикальных сторон на нескольких мониторах не поддерживается.
- Mixed-DPI, RDP, все варианты Snap Layouts и полный набор отказов установки в чистой VM не подтверждены.
- Автоскрытие поддерживается только снизу при полной ширине и стандартной толщине без островков.
- Если артефакт не имеет Authenticode-подписи, Windows может показать предупреждение «Неизвестный издатель». SHA-256 проверяет целостность, но не заменяет подпись.

Полная матрица фактически выполненных проверок приведена в [`docs/VERIFICATION.md`](https://github.com/sykia/umbrella-shell/blob/v1.0.0/docs/VERIFICATION.md).
