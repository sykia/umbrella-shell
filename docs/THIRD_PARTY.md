# Зависимости и лицензирование

Qt 6.8.3 используется динамически; условия зависят от лицензии выбранной
поставки (commercial либо применимые open-source лицензии модулей).
До распространения включить license notices/texts фактически поставляемых
Qt/runtime компонентов и обеспечить выполнение условий выбранной лицензии.
Этот файл не заменяет лицензионные тексты Qt и не предоставляет права на них.

WinSparkle пока только выбран архитектурно и не поставляется.
Inno Setup используется как build tool и генерирует installer/uninstaller;
проверить условия зафиксированной версии перед коммерческой поставкой.
Лицензия собственного кода пока не выбрана владельцем проекта. Файл LICENSE
намеренно не содержит придуманного разрешения на распространение.

Логотип assets/umbrella.png предоставлен владельцем проекта для приложения;
отдельная лицензия или права третьих лиц этим документом не устанавливаются.

Визуальный референс настроек: https://github.com/ilyamiro/serpantinum .
Код и ассеты этого проекта не копировались; QML реализован заново по референсам пользователя.
