# Зависимости и права

Автор собственного кода — sykia. Отдельная лицензия проекта пока не выбрана;
публикация исходников/бинарников сама по себе не предоставляет дополнительной
лицензии на собственный код. Логотип assets/umbrella.png предоставлен владельцем;
права на сторонние товарные знаки этим документом не устанавливаются.

## Поставляемые компоненты

- Qt 6.8.3, динамические runtime Core/Gui/Network/OpenGL, Qml/Quick/Controls/Layouts,
  QML plugins и Svg из официальной MSVC 2022 x64 поставки. Библиотека OpenGL
  входит в closure Qt; приложение явно выбирает D3D11. Неиспользуемый software
  OpenGL opengl32sw.dll исключён из deployment.
- Qt-модули и встроенные в них сторонние компоненты сохраняют свои лицензии.
  [Тексты, upstream notices, attribution и corresponding source](licenses/qt-6.8.3/README.md)
  включены в пакет, а не заменены пересказом. Набор уведомлений содержит также
  необязательные компоненты соответствующих исходных модулей.
- MSVC runtime/D3Dcompiler: app-local Microsoft redistributables от установленного
  SDK/toolchain, регулируются условиями Microsoft. Системные DLL Windows вручную
  не копируются. Win32/Direct2D/UI Automation/Windows Runtime — системные API.
- Inno Setup 6.4.3 генерирует installer/uninstaller; это build tool, не updater.
- PySide6 6.8.3 используется только в разработческом просмотре/тестах, не в приложении.

Сборка записывает относительные пути, версии и SHA-256 фактически поставленных
exe/DLL в **docs/runtime-inventory.json** внутри пакета. Этот inventory — список
файлов, а не заявление о проведённом полном лицензионном или security-аудите.
При изменении Qt/deployment нужно повторно проверить состав и уведомления.
Замена динамических Qt-библиотек совместимой собственной сборкой не блокируется.

WinSparkle и Windhawk не поставляются. Native taskbar/menu DLL реализованы в
проекте. [Serpantinum](https://github.com/ilyamiro/serpantinum) использовался как
визуальный референс; по истории разработки его код/ассеты не копировались.
Старые неиспользуемые SVG-ресурсы не означают наличие тем/активности в приложении.
