# Зависимости и права

Собственная лицензия проекта пока не выбрана владельцем. Наличие публичного
репозитория не добавляет разрешений на использование/распространение кода.
Автор проекта — sykia. Логотип `assets/umbrella.png` предоставлен владельцем;
отдельная лицензия на него этим документом не устанавливается.

## Используемые компоненты

- Qt 6.8.3: Core, Gui, Qml, Quick и импортируемые Qt Quick QML-модули,
  динамическое развёртывание средствами Qt. Условия зависят от конкретной
  commercial/open-source поставки и состава deployment.
- MSVC 2022 runtime: app-local deployment через CMake InstallRequiredSystemLibraries.
  Распространение регулируется условиями выбранной поставки Microsoft.
- Windows SDK / Win32 / D3D11 / Direct2D / UI Automation / Windows Runtime:
  системные API, без собственной поставки системных DLL Windows.
- Inno Setup 6.4.3: инструмент сборки installer/uninstaller.
- PySide6 6.8.3: отдельные разработческие QML-тесты/просмотр, не Python runtime приложения.

WinSparkle не подключён и не поставляется. Windhawk и его движок не являются
зависимостями. Native taskbar/menu DLL и протоколы находятся в исходниках проекта.
Визуальный референс настроек — [Serpantinum](https://github.com/ilyamiro/serpantinum);
код и ассеты этого проекта по имеющейся истории разработки не копировались.
Неиспользуемые SVG в assets не означают наличие старых функций в приложении.

## Условие распространения бинарников

До публичной поставки составить перечень фактических runtime-файлов и лицензий,
включить необходимые тексты/уведомления Qt и прочих компонентов, выполнить
применимые условия выбранных лицензий. Этот обзор не заменяет такие тексты
и не подтверждает, что комплект уже готов. Неизвестные права/ключи/сертификаты
не должны выдаваться за выбранные или существующие.
